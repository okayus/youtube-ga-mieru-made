# ニュースから層へ

tech ニュースを 1 件ずつ調べ、この教材のどの層（章・場面）の話かに結びつけるノート。

## 一覧

| ニュースの日付 | ノート | 主な層（章） | 状態 |
|---|---|---|---|

## 書き方

- ファイル名は `YYYY-MM-DD-題.md`。日付はニュースが出た日。
- 冒頭に出典と調べた時点を書く。続きのあるニュースは、追記した時点も書き足す。
- 節は次の順に置く。当てはまらない節は省く。
  1. 要点: どの層の話かを最初の文に書く。
  2. 確かなことと、確かでないこと: 項目・内容・出どころ・確かさの表。公式・研究者の報告・未確認を書き分ける。
  3. どの層の話か: 層・このニュースで起きること・章と場面の表。教材に無い層は「教材に無い」と書き、近い場面を添える。
  4. 層ごとの守り（または影響）: 対策や影響が層ごとに違うときだけ置く。
  5. 追って確かめること。
  6. 出典。
- 章へのリンクは公開版の場面を指す（`https://okayus.github.io/youtube-ga-mieru-made/chapters/09-os.html#s3` は第9章 場面3）。
- 文章は [docs/authoring.md](../docs/authoring.md) §8 に従う。

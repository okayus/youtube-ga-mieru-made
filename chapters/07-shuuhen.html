入出力と周辺機器

CPU とメモリだけでは、キーを押すことも、画面に出すことも、ネットワークにつなぐこともできない。この章では、CPU の外側にある装置とのやりとりを追う。速さの違う道（メモリバス・PCIe・USB）、装置のレジスタをアドレスで読み書きする仕組み（MMIO）、装置から CPU を呼ぶ合図（割り込み）、CPU を介さずにメモリへ書く仕掛け（DMA）、そしてキーボードのクリックがどう数字になり、ネットワークカードがどうビット列を電線に出すかまで。最後の NIC と Wi-Fi カードが、第11章以降のネットワークの出発点になる。

1バスの階層 — 近いほど太く、遠いほど細い

DDR5PCIeUSB

CPU は1本の道で全部につながっているのではない。メモリへは専用のメモリバス、GPU や SSD へは PCIe、キーボードへは USB。装置ごとに必要な太さの道を使い分ける。

PCIe の世代とレーン数は起動時に両端が折衝して決まり（リンクトレーニング）、lspci -vv の LnkSta で見える。USB も接続時に装置が対応する速さで決まる。値はどれも規格の理論値で片方向。USB4 の版 2.0（2022 年）は 80 Gb/s。

2デバイスレジスタと MMIO

load / store0xFEB0_0000

CPU が装置と話す方法は 1 つしかない。装置の中の小さな記憶（レジスタ）にアドレスを付け、メモリと同じ load/store で読み書きする。

PCIe 装置のレジスタの範囲（BAR）は起動時にファームウェアと OS が決めて割り当てる。x86 にはメモリとは別の 64K 個の I/O ポート空間（in/out 命令）も残っているが、現代の装置はほぼ MMIO を使う。ARM にはメモリマップしかない。

3割り込み — 装置が CPU を呼ぶ

IRQAPICIDT

装置の用事は、CPU の時間感覚からすると滅多に起きない。聞き続ける（ポーリング）代わりに、装置の側から CPU に合図を送り、CPU はそのときだけ対応する。

x86 のベクタは 256 個で、0〜31 は CPU 自身の例外に予約、装置は 32 以降。線で引く割り込みは本数が限られる（古い PC で 15 本）が、MSI-X なら装置 1 つで最大 2,048 本のベクタを持て、NIC は受信キューごとに別のコアを呼べる。

4DMA — 装置が自分でメモリへ書く

ディスクリプタIOMMU

届いたデータを CPU が 1 語ずつ運ぶのは遅く、CPU もふさがる。装置に「メモリのこの場所に書いてよい」と教え、装置が自分で書く。これが DMA で、ネットワークもディスクも GPU もこれで動く。

PCIe の 1 回の書き込みは最大 128〜512 バイト（Max Payload Size）で、中身 1,500 バイトのフレームは数回に分けて運ぶ。NIC のリングは数百〜数千個のディスクリプタを持ち、10 Gb/s では毎秒最大約 1,490 万フレームが届きうる。

5キーボードとマウス — 押した・動かしたが数字になる

マトリクスUSB HIDkeydown / click

キーは第1章のスイッチそのもの。キーボードの中のマイコンが、どのスイッチが閉じたかを格子で調べ、決まった形の数バイト（HID レポート）にして USB で送る。OS がそれを文字やクリックに変える。

USB の「割り込み転送」は名前と違い、ホストが決めた周期で読みに行く転送で、装置が割り込むわけではない（場面 1）。新しいレポートが無ければ装置は NAK を返し、ホストは何もしない。レポートのどのバイトが何かは、接続時に装置が申告する。

6NIC と Wi-Fi カード — ビット列が信号になる所

MACPHY1000BASE-T

ネットワークカード（NIC）は、メモリ上のビット列を電線の信号に変え、電線の信号をビット列に戻す装置。フレームの組み立てを受け持つ MAC と、信号との変換を受け持つ PHY の 2 段でできている。

1000BASE-T は 4 対を同時に双方向で使うので、PHY は自分の送信を受信から差し引く（エコーキャンセル）。2.5G／10GBASE-T も同じ 4 対で、シンボルの速さと段階数を増やして速度を上げる（10GBASE-T は PAM-16、毎秒 8 億シンボル）。

7まとめ — CPU の外側とのやりとり

  1. 装置は速さの違う道でつながる。メモリバス（数十 GB/s）、PCIe（レーン数と世代で選ぶ）、USB（ホスト主導）。細い道の多くはチップセットがまとめる（1）。
  2. 装置のレジスタにはアドレスが付いていて、CPU は普通の load/store で装置を動かし、状態を読む（MMIO）。触れるのはカーネルのドライバだけ（2）。
  3. 装置の用事は割り込みで知らせる。コントローラが番号を付け、CPU は状態を保存してベクタ表のハンドラへ飛び、終われば続きに戻る（3）。
  4. データの運搬は装置自身が DMA でメモリに書く。CPU はディスクリプタで置き場所を教え、完了の割り込みをまとめて受ける（4）。
  5. キーボードは格子のスキャンで押されたキーを見つけ、8 バイトの HID レポートにする。OS がキーコードを文字に、ボタンをクリックにして、ブラウザのイベントになる（5）。
  6. NIC は MAC がフレームを組み立て、PHY がビットを電線の信号にする。Wi-Fi カードは PHY の先が電波。ここから先が第11章以降のネットワーク（6）。
バス複数の装置が共有する、または装置ごとに引いた信号の道。メモリバス、PCIe、USB、SATA など。
PCIe（レーン）送受 1 組の差動線が 1 レーン。×1 / ×4 / ×16 と束ねる。Gen3 0.985、Gen4 1.97、Gen5 3.94 GB/s（1 レーン・片方向）。
USBホストが主導するシリアルバス。2.0 は 480 Mb/s、3.2 は 5〜20 Gb/s、USB4 は 40 Gb/s（版 2.0 は 80）。キーボードは割り込み転送で 1〜8 ms ごとに読まれる。
デバイスレジスタ・MMIO装置内の制御・状態・データのレジスタに物理アドレスを割り当て、load/store で読み書きすること。範囲は PCIe の BAR で決まる。
ポーリング状態レジスタを繰り返し読んで待つ方法。単純だが CPU 時間を浪費する。
割り込み（IRQ・MSI）装置から CPU への合図。割り込みコントローラ（APIC / GIC）がベクタ番号を付け、CPU はベクタ表（IDT）のハンドラへ飛ぶ。
ハンドラ・EOI割り込みを処理するカーネルの関数。装置と話し、コントローラに処理済み（EOI）を伝え、保存した状態を復元して戻る。
DMA・ディスクリプタ装置が直接メモリを読み書きする仕組みと、置き場所（アドレスと長さ）を書いたメモリ上の表。リング状に並べる。
IOMMU装置のメモリアクセスを翻訳・制限する装置用ページテーブル。Intel VT-d、AMD-Vi、ARM SMMU。
HID レポートUSB の入力装置が送る決まった形のバイト列。キーボードは 8 バイト（修飾キー 1、予約 1、キーコード 6）。
MAC・PHYNIC の 2 段。MAC はフレームの組み立てと FCS、宛先の確認。PHY はビットと信号（電圧・光・電波）の変換。

Wi-Fi

パソコンの Wi-Fi カード（第7章）から出た 0 と 1 の列は、アンテナの中の電子の往復で電波になり、空気中を進んでルーターに届く。この章では電波とは何かから始めて、ビットを波に乗せる変調、多数の搬送波で並列に送る OFDM、順番を譲り合う CSMA/CA、接続と暗号化（WPA2／WPA3）、そして同じ Wi-Fi でも速さが変わる理由までを追う。

構成

  1. 1電波とは

    アンテナの中の電子の往復が電磁波になる。周波数と波長、受信、混ざらない理由。

  2. 2変調：ビットを波に乗せる

    ASK・PSK・QAM と星座図。点が多いほど速く、ノイズに弱い。

  3. 3OFDM：多数の波で並列に

    64 本のサブキャリア、直交、ガードインターバル、Wi-Fi 6 の OFDMA。

  4. 4フレームと CSMA/CA

    802.11 フレーム、聞いてから送る、ACK と再送、隠れ端末。

  5. 5接続と暗号化

    ビーコンから 4-way handshake まで。PMK・PTK、AES-CCMP、WPA3 の SAE。

  6. 6速さが変わる理由

    距離と壁、SNR と MCS、チャネル幅、干渉、MIMO、周波数帯の使い分け。

  7. 7まとめ

    要点と用語。次の章（Ethernet とスイッチ）へ。

図はすべて模式図。電波の波長・速さ・本数、サブキャリアの数は見やすく変えてある。数値は規格値か目安で、場面6の距離・受信電力・速度は簡単なモデルで計算した例。

1電波とは

2.4 / 5 / 6 GHzλ = c / f

Wi-Fi カードの出口はアンテナ。そこで電子を高速に往復させると、まわりの電場と磁場の変化が光速で広がる。それが電波で、光と同じ電磁波の仲間である。

日本の割り当て（2026 年時点）は、2.4 GHz 帯が 2.400〜2.4835 GHz、5 GHz 帯が 5.15〜5.35 と 5.47〜5.73 GHz、6 GHz 帯（Wi-Fi 6E 以降）が 5.925〜6.425 GHz。電子レンジも 2.45 GHz を使う。

2変調：ビットを波に乗せる

ASK / PSK / QAM星座図

一定の波（搬送波）は、それだけでは何も伝えない。ビットに合わせて波の振幅や位相を切り替える操作が変調で、1 回の切り替えで送る単位をシンボルと呼ぶ。

実際に運べるデータ量は、このビット数に誤り訂正の符号化率（1/2〜5/6）を掛けたもの。変調と符号化率の組を MCS と呼び、電波の状態に合わせて選び直す（6「速さが変わる理由」）。

3OFDM：多数の波で並列に送る

20 MHz = 64 本3.2 µs + GI

Wi-Fi は 1 本の速い波ではなく、帯域を細かく分けた多数のサブキャリアに、それぞれゆっくりシンボルを乗せる。壁の反射で遅れて届く電波に強く、帯域を隙間なく使える。

パイロットは中身が決まった基準の波で、受信側はこれで位相と振幅のずれを測って補正する。データ用は 802.11a/g で 48 本、802.11n/ac で 52 本、Wi-Fi 6 の 20 MHz では 256 本のうち 234 本。

4フレームと CSMA/CA

DIFS 34 µsSIFS 16 µsACK

同じチャネルの端末は同じ空気を共有する。誰かが送っている間は他の全員が待ち、空いたら乱数で順番をずらして送る。届いたかどうかは ACK で確かめる。これが CSMA/CA。

値は 5 GHz 帯のもの。スロット 9 µs、SIFS 16 µs、DIFS ＝ SIFS ＋ 2 スロット ＝ 34 µs。いまの Wi-Fi（WMM）は DIFS の代わりに通信の種類ごとの AIFS を使い、ふつうのデータは SIFS ＋ 3 スロット ＝ 43 µs。

5接続と暗号化

SSID4-way handshakeWPA2 / WPA3

端末が AP に「つながる」までには、見つける・名乗る・鍵を作る、の 3 段がある。パスフレーズそのものは電波に乗せず、両者が同じ計算をして同じ鍵にたどり着く。

PMK は 256 ビット。PTK は WPA2-CCMP で 384 ビットで、KCK（MIC 用 128）・KEK（GTK の暗号化用 128）・TK（データ暗号化用 128）に分けて使う。GTK はブロードキャスト用に AP が全端末へ配る。

6速さが変わる理由

RSSI / SNRMCSMIMO

同じルーターでも、部屋を移ると速さが変わる。電波が弱まると粗い変調に落ち、チャネルを共有する相手が増えると待ち時間が増える。箱に書かれた最大速度との差はここから生まれる。

表の速度は Wi-Fi 6・80 MHz 幅・1 ストリーム・GI 0.8 µs の規格値。雑音 −89 dBm は 80 MHz 幅の熱雑音に受信機の雑音約 6 dB を足した目安。dBm は 1 mW を 0 dB とした対数表示で、10 dB 下がると 1/10。

7まとめ — 電波で 0 と 1 を運ぶ

  1. アンテナの中の電子の往復が電波になる。周波数が波長を決め、2.4 GHz で 12.5 cm（1）。
  2. ビットは搬送波の振幅と位相（I/Q の点）に乗せる。点が多いほど速く、雑音に弱い（2）。
  3. 帯域を多数のサブキャリアに分けて並列に送るのが OFDM。反射に強く、直交で隙間なく使える（3）。
  4. 空気は共有線。聞いてから乱数で待って送り、ACK で確認し、だめなら再送する（4）。
  5. 接続はビーコン→認証→アソシエーション→4-way handshake。パスフレーズは送らず、両者が PMK から PTK を作る（5）。
  6. 距離・壁・干渉で SNR が下がると MCS が落ちる。チャネル幅、MIMO、周波数帯が速さを左右する（6）。

次の章（Ethernet とスイッチ）では、銅線の信号、Ethernet フレーム、スイッチ、ARP を見たあと、AP が 802.11 フレームを Ethernet フレームに組み替える所（第13章の場面6）でこの章とつながる。

電磁波・電波電場と磁場が互いを生みながら光速で進む波。Wi-Fi は 2.4 / 5 / 6 GHz 帯。波長 λ ＝ c ÷ f。
変調・シンボル搬送波の振幅・位相をビットで切り替えること。1 回の切り替えがシンボル。BPSK 1 ビット〜4096-QAM 12 ビット。
星座図（I/Q）cos 成分 I と sin 成分 Q を軸にした点の地図。受信側は最も近い点を選ぶ。SNR が低いと点を取り違える。
OFDM・サブキャリア帯域を間隔 312.5 kHz（Wi-Fi 6 は 78.125 kHz）の多数の搬送波に分け、各 3.2 µs（12.8 µs）のシンボルを並列に送る方式。
ガードインターバルシンボルの前に付ける 0.4〜3.2 µs の余白（規格による）。反射波の遅れを吸収する。
CSMA/CA聞いて、DIFS と乱数スロットぶん待って送り、ACK で確認する媒体アクセス制御。衝突は検出できないので避ける。
SSID・BSSIDネットワークの名前と、AP の MAC アドレス。ビーコンで約 100 ms ごとに知らされる。
PMK・PTK・GTKパスフレーズと SSID から作る親鍵、接続ごとに乱数から作る鍵、全員宛て用の鍵。4-way handshake で PTK を確認し GTK を配る。
WPA2 / WPA3AES-CCMP で暗号化。WPA3 は SAE で鍵交換し、録音からの総当たりを防ぎ、前方秘匿性を持つ。
MCS・MIMO変調と符号化率の組（Wi-Fi 6 は 0〜11）。SNR に応じて選ぶ。MIMO は複数アンテナで空間ストリームを同時に送る。

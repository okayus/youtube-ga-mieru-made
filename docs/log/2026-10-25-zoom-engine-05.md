## 3. 作りの決めごと（第6章から増えた分）

- **`.fade` を付けた要素を消す対象にしない**: 05 の `st.g` は `onStep` で `S.fade` されるので `.fade`（opacity の 0.35 秒の transition）が付く。板の開閉で付ける inline の opacity が遅れるので、`.fade` の無い親 `st.gw` で包んで `make` に渡した。
- **粒は `Math.random` で散らさない**: 断面の電子・正孔は `hash(k, s)`（sin の疑似乱数）で決まった位置に置き、揺れは時刻の sin。`--nav` で道に依らない。
- **隠れている部分も毎フレーム描く**: 最初は「輪」の段階（アクセス部を非表示）でアクセス部の文字を更新していなかったので、`--nav` が「段階5 → 段階1 で text『』→『オン』」の注意を 2 件出した。非表示でも同じ式で描くようにして 0 件。
- 回路記号は第3章の `mosSym` と同じ形（`mos()`。`flip` で左右を返してゲートを右に、`rot` で 90° 回してゲートを上に）。たすき掛けの交差は小さく跳ねて「つながっていない」ことを示す。

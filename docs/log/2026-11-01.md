## 仕上げ確認（別の担当。直したのは章のファイルだけ）

- 場面6 段階1 で、カートリッジの図（ヘッダ・SRAM・出力の箱・SAMPLE.SAV・Enter の札）が丸ごと消えていた。`st.sramLbl = svg.lastChild` が文字ではなく図の g を指し、段階1 で g ごと display:none になっていた（調整役も写真で見つけていた）。
- 場面5 段階6 の遅れの計算の誤り: 閉包は size() ≤ 8,192 を見てから 4,096 バイトを積むので、キューの最大は 12,288 バイト ＝ 1,536 組 ＝ 32 ms。「キュー 32 ms ＋ 装置 21 ms ＝ 最大 50 ms ほど（計算上）」に直し、plan.md の 40 ms も 50 ms にした。
- 場面4 の格子・窓・階調の表の塗りがテーマ色で、ダークモードでは階調 0 が暗く 3 が明るく出て表の値（255・173・82・0）と逆だった。実際の階調の色（#fff／#adadad／#525252／#000）の固定値にした（調整役も見つけていた。画素の実際の値なので直書きを許した）。
- 場面3 の IF ビット 4 を「押している間 1、離すと 0」で描いていたが、本体は button_up で IF を触らず、CPU が受け付けたとき（cpu.rs 86）に 0 に戻す。押した瞬間に立ち 0.6 秒後に戻す描き方にし、注記「IME と IE が許せば本体の CPU が受け付け、受け付けると 0 に戻る」を足した。IF の 1 は凡例どおり割り込みの色（e）で塗る（場面6 の IF ビット 3 も）。補足の「下位のビットが 1 から 0 に」を「選んだ組の下位のビットが」に（Pan Docs）。
- 場面1 段階3 の「`sdl2::init()` は OS の窓・音・入力の層をまとめて開き」は誤り。sdl2 0.35.2 の init() は SDL_Init(0) で、窓は LCD::new の `sdl.video()`、音は Audio::new の `sdl.audio()` が開く。段階5 の「第6章〜第8章」のリンクを表紙・まとめと同じ「第4章〜第8章」に。
- 場面4 段階6 の「SDL のテクスチャは GPU のメモリ」→「多くの環境で GPU のメモリに置かれ」（既定のレンダラはソフトウェア描画もあり得る）。図の「× 59.73 回/秒」→「約 60 回/秒」。
- 場面5 段階2 の図「Rc::new(audio.0) → Rc<dyn Fn(&[f32])>」→ 実際の型は Rc<Box<dyn Fn>> で、Box も Fn なので Rc<dyn Fn> として渡せる（unsized coercion）。
- コードの板の右端からはみ出す・接する行を 9 か所で折り返し、照らす行の添字を合わせた。場面4 段階1 の札の重なり、段階2 の「(3, 2) はこのマスの中」を不透明な札に。場面6 の Enter の札と出力の箱の重なり（カートリッジの箱を 10px 高く）。

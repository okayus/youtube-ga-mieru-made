## 1. 通しで進む導線

利用者の依頼: 「表紙からすべてのページを順番に確認する導線がないので作って。一回一回各章のページに行かずにすべてを通しで見たい」。それまでは → ← が場面の中の段階だけ、↓↑ と ‹ › が章の中の場面だけを動かし、章の端で止まっていた。章を移るには、まとめの「次の章」を押すか目次へ戻る必要があった。

| ファイル | 変更 |
|---|---|
| assets/engine.js | 1画面版の → を「次の段階 → 次の場面 → 次の章（`meta.next`）の表紙」、← をその逆（前の場面は最後の段階から、前の章は `#last` で最後の場面から）に。↓↑ と右上の ‹ › は場面ごとで、章の端では前後の章へ（‹ › の題も「次の章へ：…」に変わる）。`meta.prev` が無い章の前は目次の最後の場面。`#last` で最後の場面を開く。段階の操作欄は最後の段階で「次へ」を隠して「次の場面へ →」を出す。「自動で進む」は 1画面版では段階・場面・章をまたぐ（段階の無い場面は `def.dur`／`stillDur` 既定 15 秒）。今いる章と場面を localStorage の `ytm-last` に残す |
| index.html | 表紙の始める欄を「最初から通して見る」に、前回の場面があれば「続きから 第N章 題・場面K」を足す。目次の最後の場面（使い方）の次を第1章に（`meta.next`）。表紙の操作の説明と使い方の表を通しの操作に |
| README.md・docs/authoring.md §3 | 操作と仕組みの説明 |

縦読み版（スマートフォン）はスクロールで読み進め、章の最後のまとめに「次の章」があるので変えていない。

### 確かめたこと

ヘッドレス Chrome（1920×880）で、目次の表紙から → を押し続けると、目次の 4 場面 → 第1章の全段階 → 第2章の表紙へ進んだ。第2章の表紙で ← を押すと第1章のまとめ、さらに ← で場面6 の最後の段階。↑↓ は段階を変えずに場面だけ移る。第1章のまとめで ‹ › の題は「次の章へ：半導体とダイオード（↓キー）」。最後の段階で「次へ」が隠れて「次の場面へ」が出て、押すと次の場面へ。目次の表紙に「続きから」が出る。第1章の表紙で ← を押すと目次の使い方。「自動で進む」で第1章のまとめの待ち時間を過ぎると第2章の表紙へ。第25章のまとめでは → で何も起きず、› は押せない。

## 2. 作り直し: 右下の操作欄にまとめる

利用者の指摘: 「『第1章から最初から通して見る』ボタンをクリック後に表示されて欲しいのは『次の章 半導体とダイオード』のボタンではなく、一ページずつ進められるボタンがあり、その章の最後ページで次へ進めたら次の章に進むことです。進むボタンと次の章に進むボタンが離れた位置にあるのは体験が良くない」。

1. の作りでは、→ キーは章をまたげたが、画面の上の「進む」ボタンは 3 か所に分かれていた（説明欄の「次へ」、右上の小さな ‹ ›、表紙とまとめの「次の章」）。章の表紙でいちばん目立つのは「次の章」のボタンで、押すと章を飛ばしてしまった。

| ファイル | 変更 |
|---|---|
| assets/engine.js | 右下に操作欄（`.navdock`）を出す。「← 前へ」・今の位置（「3 / 8　段階 2 / 5」）・「次へ →」。「次へ」は 1 段階ずつ（段階の無い場面は 1 場面）進み、章の最後のページでは「次の章へ：題 →」と書いて次の章の表紙へ。第1章の表紙の「前へ」は「← 目次へ」、第25章の最後は「おわり」。上部バーの右の ‹ › と、1. で足した「次の場面へ」ボタンは外した |
| assets/base.css | 操作欄の見た目。場面の下に操作欄の分の 46px を空けた（`.fit .scene` の下の余白 18 → 64px、表紙 22 → 68px）。1画面版では説明欄の「前へ」「次へ」と、章の表紙・まとめの「次の章」（`.chnav[data-auto] .next`）を隠す |
| index.html | 表紙の操作の説明と使い方の表を右下の操作欄に |
| README.md・docs/authoring.md §3・§6 | 操作と仕組み、高さの予算（本体は約 668px） |

### 確かめたこと

ヘッドレス Chrome（1920×880）で本物のマウスの押下を送って試した。目次の表紙の「最初から通して見る」→ 第1章の表紙（「← 目次へ　1 / 8　次へ →」）→「次へ」を 33 回押すと第1章の全 33 ページ（表紙・31 段階・まとめ）を順に進み、まとめで「次の章へ：半導体とダイオード →」→ 第2章の表紙。第2章の表紙の「← 前の章へ」で第1章のまとめへ。第25章のまとめは「おわり」（押せない）、目次の使い方は「次の章へ：電子と電流 →」。

### 高さの確認

`node tools/verify.mjs --nav --sizes all index.html chapters/*.html`（1920×880・1536×730・1366×657・1280×688）で全 26 ページ失敗なし。各章の「最も余裕のない場面」の余りは 9px 以上（操作欄の分の 46px を空けた後）。目次の場面1（全体の地図）だけ余りが −6〜−29px で、1280×688 では図の説明の 2 行目が下の色の説明の行に重なっていた（HTML の文字どうしなので `--overlap` では拾えない）。地図の図の最大の高さを 600 → 556px にして、余りは 15px 以上になった。段階の行き来の注意は前からある 02 章 場面6 の 9 件だけ。

## 4. 上部バーの › に集める（右下の操作欄はやめた）

利用者の依頼: 「index.html にある //*[@id="pg-next"] をクリックしたら chapters/01-denshi.html#s1 に遷移し、7まとめ で //*[@id="pg-next"] をクリックしたら chapters/02-handoutai.html#s1 に遷移してほしい。次へボタンだけ押していれば順番に全ページ見れるようにして」。

`#pg-next` は 2. で外した上部バーの › だった。利用者のブラウザは古い engine.js を使い続けていた（`python3 -m http.server` は Cache-Control を返さず、ブラウザが前の写しを使った）と考えられる。
